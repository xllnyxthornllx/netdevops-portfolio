## 🚀 Proyectos Destacados

* **[Cupora](https://github.com/xllnyxthornllx/Cupora):** Plataforma integral PWA de reserva, control de aforo y despacho interurbano en tiempo real para minivanes (React 18, TypeScript, Tailwind CSS, escáner de boletos QR offline con cámara, integración de pagos Yape/Plin y bus de sincronización BroadcastChannel).
* **[NYXCORE Cloud Homelab](https://nyxcore.online):** Servidor físico de alta disponibilidad (Ubuntu Server 26.04) que ejecuta 17 microservicios en Docker, ZRAM zstd en memoria, túneles Cloudflare Zero Trust sin puertos abiertos y VPN WireGuard/Tailscale.
* **[NYXCORE Autonomous AI DJ 8.0](https://iot.nyxcore.online/dj/):** Motor de streaming Web Audio DSP dual-deck en tiempo real con mezcla armónica (Rueda de Camelot), 7 modos de transición pro, orbes 3D reactivos a 60 FPS y locuciones neuronales de DJ Elvira.
* **PetFeeder-IoT & Invernadero SCADA:** Automatización de dispensado y monitoreo ambiental mediante ESP32, broker MQTT Mosquitto y flujos reactivos en Node-RED.
* **Automatización NetDevOps Cisco/Fortinet:** Pipeline de scripts en Python con Netmiko y APIs RESTCONF para rotación masiva de credenciales y auditorías de configuración idempotentes.

## ✨ Características de la Web

- **Arquitectura Vanilla:** TypeScript puro y HTML/CSS semántico empaquetado con Vite, con bundle ultraligero y rendimiento óptimo.
- **Animaciones GSAP 3:** Efectos de inclinación 3D (Tilt interactivo), textos revelados caracter a caracter y parallax sutil.
- **Lenis Smooth Scroll:** Navegación fluida e inmersiva adaptada a pantallas táctiles y escritorio.
- **Copia de Correo 1-Clic:** Sistema unificado que copia `torressalazarurielaron@gmail.com` al portapapeles con toast flotante visual y fallback seguro.
