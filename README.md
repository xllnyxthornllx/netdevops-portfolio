Portafolio personal e interactivo enfocado en la convergencia entre la infraestructura de redes (NetDevOps) y el desarrollo de software. Diseñado con una arquitectura de alto rendimiento, sin frameworks pesados, priorizando la fluidez y la experiencia de usuario.

🔗 **[Ver Despliegue en Vivo (Vercel)](https://netdevops-portfolio.vercel.app/)**

## ✨ Características Principales

- **Arquitectura Vanilla:** Construido puramente en TypeScript y HTML/CSS semántico, empaquetado con Vite para un rendimiento extremo y tiempos de carga mínimos.
- **Animaciones Cinematográficas (GSAP):** Implementación de efectos 3D (Tilt), revelado de texto y microinteracciones utilizando GreenSock Animation Platform.
- **Smooth Scrolling:** Integración de Lenis Scroll para una navegación fluida e inmersiva independiente del dispositivo o navegador.
- **Contacto Infalible:** Sistema dual de contacto que copia automáticamente el correo al portapapeles mediante la API nativa del navegador, respaldado por un fallback de seguridad y notificaciones visuales (Toast) personalizadas.
- **Diseño Bento Grid:** UI/UX moderna basada en componentes asimétricos estilo cristal (Glassmorphism) totalmente responsiva (Mobile-First).

## 🛠️ Stack Tecnológico

- **Core:** HTML5, CSS3 (Variables, Flexbox/Grid, Custom Properties), Vanilla TypeScript.
- **Animación & UX:** GSAP (Core & ScrollTrigger), Lenis.
- **Tooling:** Vite, Node.js.
- **Despliegue:** Vercel (CI/CD automático).
